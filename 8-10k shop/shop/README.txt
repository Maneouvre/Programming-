SHOP (no database needed)
1. Edit config.php: shop name, WhatsApp number (254...), and admin password.
2. Upload all files to htdocs, keeping the admin, uploads and data folders.
3. Open yoursite/admin/login.php to manage products and announcements.
4. Product photos are stored in admin/uploads/. Announcement photos are stored separately in admin/slideshow_uploads/ and announcement text in data/slides.json.
Customers see yoursite/index.php
